## 案例一：邻市政务数据共享平台

- **项目 / 客户 / 实施对象**：邻市大数据管理局"政务数据共享平台"**项目**，实施对象为该局及所属各委办局。
- **实际实施内容**：完成多部门数据归集、建成统一共享接口、部署数据质量治理规则库，覆盖归集、
  共享、监测全链路。
- **实施 / 上线 / 验收 / 应用状态**：该项目**已上线运行**，并**通过第三方验收**，目前处于**稳定应用**
  阶段，持续为各部门提供数据共享服务。

## 案例二：某省属集团数据中台

- **项目 / 客户 / 实施对象**：某省属国有集团"数据中台"建设**项目**，实施对象为集团及下属企业。
- **实际实施内容**：建成多源数据接入通道、数据质量治理引擎与运营监测中心，接入下属企业业务系统。
- **实施 / 上线 / 验收 / 应用状态**：该项目**已完成上线**，并**通过集团验收**，现处于**常态化应用**
  与运维阶段。

以上两个同类**项目**的**实施内容**与**上线 / 验收 / 应用状态**均已明确，可佐证本方案所述能力
已在实际工程中落地实施。
